================================================================================
1. OVERVIEW
================================================================================

The CNN Denoising Library is a high-performance image denoising system
implemented in OpenCL. The library provides real-time inference capability
on modern GPUs through aggressive kernel optimization and efficient memory
management.

Key Characteristics:
  - Real-time performance: 4.31ms inference at 800x600 resolution
  - Throughput: 231.9 frames per second
  - Memory efficient: Float4 vectorization with minimal padding
  - Training support: Full backpropagation with SGD optimizer

================================================================================
4. ARCHITECTURE
================================================================================

4.1 Network Structure
---------------------
The library implements a convolutional encoder-decoder architecture:

  Layer 0 (encoder1):    4 -> 24 channels, 3x3 kernel, ReLU
  Layer 1 (bottleneck): 24 -> 48 channels, 3x3 kernel, ReLU
  Layer 2 (decoder1):   48 -> 24 channels, 3x3 kernel, ReLU
  Layer 3 (output):     24 ->  4 channels, 3x3 kernel, Linear

  Total parameters: 22,564

4.2 Kernel Optimization
-----------------------
The forward convolution kernel processes 4 output channels per thread,
significantly reducing memory bandwidth requirements through input data reuse.

Work group configuration:
  Global size: {width, height, (channels + 3) / 4}
  Local size:  {16, 8, 1}

5. API REFERENCE
================================================================================

5.1 Core Functions
------------------

CNNDenoiser* cnn_create(CNNConfig config)
  Create new CNN instance with specified configuration
  
  Parameters:
    config.input_width     - Image width in pixels
    config.input_height    - Image height in pixels
    config.input_channels  - Number of input channels (must be 4)
    config.output_channels - Number of output channels (must be 4)
    config.learning_rate   - Learning rate for training
    config.use_profiling   - Enable OpenCL profiling (0 or 1)
  
  Returns:
    Pointer to CNNDenoiser structure, or NULL on failure


int cnn_add_layer(CNNDenoiser* cnn, LayerConfig layer)
  Add convolutional layer to network
  
  Parameters:
    layer.cin      - Input channels
    layer.cout     - Output channels
    layer.use_relu - Apply ReLU activation (1) or linear (0)
    layer.name     - Layer name (up to 63 characters)
  
  Returns:
    0 on success, -1 on failure


int cnn_finalize(CNNDenoiser* cnn)
  Finalize network and allocate GPU buffers
  Must be called before training or inference
  
  Returns:
    0 on success, -1 on failure


float cnn_train_step(CNNDenoiser* cnn, float* input, float* target, int batch)
  Execute one training iteration
  
  Parameters:
    input  - Noisy input image (RGBA float format)
    target - Clean target image (RGBA float format)
    batch  - Batch size (currently only 1 supported)
  
  Returns:
    Mean absolute error loss value


void cnn_destroy(CNNDenoiser* cnn)
  Release all resources and destroy CNN instance


5.2 Helper Functions
--------------------

void cnn_rgb_to_rgba_luminance(const unsigned char* rgb, float* rgba,
                                int width, int height)
  Convert RGB uint8 image to RGBA float with luminance channel
  
  Input:  RGB [H][W][3], values 0-255
  Output: RGBA [H][W][4], values 0.0-1.0
  Channel 4: Luminance = 0.299*R + 0.587*G + 0.114*B


void cnn_rgba_luminance_to_rgb(const float* rgba, unsigned char* rgb,
                                int width, int height)
  Convert RGBA float to RGB uint8 (discards luminance channel)
  
  Input:  RGBA [H][W][4], values 0.0-1.0
  Output: RGB [H][W][3], values 0-255


int cnn_prepare_training_batch(const unsigned char* clean_rgb,
                                unsigned char* noisy_rgb,
                                float* clean_rgba, float* noisy_rgba,
                                int width, int height, float noise_sigma)
  Prepare complete training batch with Gaussian noise
  
  Operations performed:
    1. Convert clean RGB to RGBA float
    2. Add Gaussian noise (sigma parameter)
    3. Clamp values to [0.0, 1.0]
    4. Optionally return noisy RGB visualization
  
  Returns:
    0 on success, -1 on failure


int cnn_inference_rgb(CNNDenoiser* cnn, const unsigned char* input_rgb,
                      unsigned char* output_rgb, int width, int height)
  Complete inference pipeline with automatic format conversion
  
  Operations performed:
    1. Convert input RGB to RGBA float
    2. Execute network forward pass
    3. Convert output RGBA float to RGB
  
  Returns:
    0 on success, -1 on failure


================================================================================
6. INPUT FORMAT REQUIREMENTS
================================================================================

6.1 Four-Channel Requirement
-----------------------------
The library requires 4-channel input for optimal GPU vectorization. Standard
RGB images (3 channels) must be converted to RGBA format with luminance as
the fourth channel.

Rationale:
  - GPU processes float4 vectors (4 floats in parallel)
  - 3-channel data causes unaligned memory access
  - Luminance channel provides additional useful information

6.2 Luminance Calculation
--------------------------
The fourth channel contains luminance computed using ITU-R BT.601 standard:

  L = 0.299 * R + 0.587 * G + 0.114 * B

This is the standard formula used in video encoding and image processing.

6.3 Data Layout
---------------
Memory layout for 800x600 image:

  [R0 G0 B0 L0][R1 G1 B1 L1][R2 G2 B2 L2]...
   \___________/ \___________/
     pixel 0       pixel 1

  Total size: 800 * 600 * 4 * sizeof(float) = 7,680,000 bytes


================================================================================
7. OPTIMIZATION DETAILS
================================================================================

7.1 Multi-Output Processing
----------------------------
Each GPU thread computes 4 output channels instead of 1, achieving 1.8x
speedup through input data reuse.

Before:
  - Thread count: width * height * num_channels
  - Each thread: Load 9 float4 inputs, compute 1 output

After:
  - Thread count: width * height * (num_channels / 4)
  - Each thread: Load 9 float4 inputs, compute 4 outputs
  - Memory bandwidth reduction: ~40%

7.2 Weight Prefetching
----------------------
All 9 weight vectors are loaded into registers before dot product
computation, improving instruction scheduling and reducing memory latency.

7.3 Gradient Clipping
---------------------
Weight updates are clamped to [-1.0, +1.0] to prevent gradient explosion
during training. This enables use of unsafe math optimizations for maximum
performance.

7.4 Loss Reduction
------------------
Loss computation uses per-workgroup reduction to avoid atomic operations
on floating-point values, which are not supported in standard OpenCL.

7.5 Memory Allocation
---------------------
All buffers use 64-byte alignment via posix_memalign for optimal memory
controller efficiency.

------------------------
Configuration: 3 -> 32 -> 64 -> 32 -> 3, forward + backward + loss

  Separate kernels:              5306 ms/iteration
  Kernel fusion:                 1735 ms/iteration  (3.06x faster)

9.1 Basic Inference
-------------------

#include "cnn_denoise.h"

int main() {
    CNNConfig config = {800, 600, 4, 4, 0.001f, 0};
    CNNDenoiser *cnn = cnn_create(config);
    
    cnn_add_layer(cnn, (LayerConfig){4, 24, 1, "encoder1"});
    cnn_add_layer(cnn, (LayerConfig){24, 48, 1, "bottleneck"});
    cnn_add_layer(cnn, (LayerConfig){48, 24, 1, "decoder1"});
    cnn_add_layer(cnn, (LayerConfig){24, 4, 0, "output"});
    cnn_finalize(cnn);
    
    unsigned char *input_rgb = load_image("noisy.jpg", 800, 600);
    unsigned char *output_rgb = malloc(800 * 600 * 3);
    
    cnn_inference_rgb(cnn, input_rgb, output_rgb, 800, 600);
    
    save_image("clean.jpg", output_rgb, 800, 600);
    cnn_destroy(cnn);
    return 0;
}


9.2 Training Loop
-----------------

#include "cnn_denoise.h"

int main() {
    CNNConfig config = {800, 600, 4, 4, 0.00001f, 0};
    CNNDenoiser *cnn = cnn_create(config);
    
    cnn_add_layer(cnn, (LayerConfig){4, 24, 1, "encoder1"});
    cnn_add_layer(cnn, (LayerConfig){24, 48, 1, "bottleneck"});
    cnn_add_layer(cnn, (LayerConfig){48, 24, 1, "decoder1"});
    cnn_add_layer(cnn, (LayerConfig){24, 4, 0, "output"});
    cnn_finalize(cnn);
    
    unsigned char *clean_rgb = load_image("clean.jpg", 800, 600);
    float *clean_rgba = malloc(800 * 600 * 4 * sizeof(float));
    float *noisy_rgba = malloc(800 * 600 * 4 * sizeof(float));
    
    cnn_prepare_training_batch(clean_rgb, NULL, clean_rgba, noisy_rgba,
                               800, 600, 0.05f);
    
    for (int epoch = 0; epoch < 1000; epoch++) {
        float loss = cnn_train_step(cnn, noisy_rgba, clean_rgba, 1);
        if (epoch % 100 == 0) {
            printf("Epoch %d: Loss = %.6f\n", epoch, loss);
        }
    }
    
    cnn_destroy(cnn);
    return 0;
}
